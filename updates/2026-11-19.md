# 2026-11-19 连接与升级维护

星爵老灯tvskill 本次更新整理 DpadTV 连接故障和 Marco Movie 升级、片源失效的修复流程，并补充红米 A50 的实机验证记录。

本次发布更新 Codex Skill 的指引与实测说明。电视安装助手当前发布版本为 v1.1.0，随包提供 Tigris 和 Marco 开放片单。官方 Marco Movie 的升级按本文链接的电视端流程处理。[安装助手 v1.1.0](https://github.com/haoxiaolong1102/xingjue-laodeng-tvskill/releases/tag/v1.1.0)

## 解决了什么

| 场景 | 本次补充的处理 |
| --- | --- |
| DpadTV 推荐为空、只显示搜索页或提示请求失败 | 分开检查本机服务与电视到片源的连接，验证同一提供方备用入口后更新客户端及服务配置 |
| 电脑能加载片源，电视却一直超时 | 在电视侧检查相同请求，比较备用入口的分类、影片 ID 和名称 |
| Marco 提示更新，安装后仍是旧版 | 读回实际版本，核验官方电视 APK 的签名、摘要与设备兼容性，完成原位升级 |
| Marco 已有来源，片库与搜索仍为空 | 在现有线路编辑接口地址，保存后复测片库、搜索和播放 |
| 升级与修复后的数据核对 | 备份并逐项比较原观看记录、收藏、订阅及续播点，检查应用重开 |

## 这次怎样验证

实测设备为 Redmi A50 2025、Android 9／API 28、32 位 ARM，固件 HyperOS OS3.0.102.0.PSTAATV。

| 项目 | 本次结果 |
| --- | --- |
| DpadTV 1.3.0 | 海报墙恢复，搜索返回 20 条结果，详情和点播通过验证 |
| Marco Movie TV | 官方版本由 0.5.23 原位升级至 0.5.26，片库、分类与搜索恢复 |
| 实际播放 | 两款应用均记录到 1920×800 H.264 硬解、音轨输出和持续增长的播放进度 |
| 现场确认 | 用户确认两款应用画面和声音正常 |
| 应用重开 | 两款应用重新打开后片库与配置通过核对 |
| 观看数据 | 原观看记录和原续播点逐项核对，测试各新增一条观看记录 |
| 本机连接 | 移除电脑端临时转发后，DpadTV 在电视上直接使用本机服务播放 |

本轮验证范围为上述设备上的目录、搜索、详情、点播和应用重开。片源接口按用户现有来源及当次可用入口配置，第三方服务的可达性需要使用时核对。
